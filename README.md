# Database Management System

CS5200 DBMS coursework repository.

## Structure

### Homework

| Directory | Topic |
|---|---|
| `Honework1Introduction.pdf` | Introduction to databases |
| `Homework2ER.pdf` | Entity-Relationship modeling |
| `homework3EER/` | Extended ER modeling — Art Museum design |
| `homework4EER/` | EER to Relational mapping |
| `homework5SQL/` | Advanced SQL — 60+ query exercises across company and mail-order schemas |
| `Homework7RelationalAlgebra/` | Relational algebra and SQL triggers |
| `homework8Normalization/` | Database normalization |

### Labs

| Directory | Topic |
|---|---|
| `lab2ERDiagram/` | ER diagram design in MySQL Workbench |
| `lab3MysqlOnGCP/` | MySQL setup on Google Cloud Platform |
| `lab3SQL/` | SQL practice — SELECT, JOIN, aggregation, update queries |
| `lab4mysqlOnGCP2/` | MySQL connection on GCP |
| `lab4python-sql-connection/` | Python–MySQL integration with demo scripts |
| `lab5Stored Procedure/` | Stored procedures, triggers, and JDBC (Java) |
| `lab6QueryProcess&Optimizer/` | Query processing and optimization |
| `lab7TransactionManagement/` | Transaction isolation levels and concurrency (Python) |

### Exams

`midterm/` contains mock exam questions and solutions. `finalexammock/` contains final exam practice questions and full solutions.

### Slides

`slides/` holds lecture slides for all modules: ER/EER modeling, SQL, relational algebra, normalization, disk storage, query processing, transaction management, and NoSQL.

### Project(unfinished)

`AI_API_Gateway_Project/` is the semester group project — an AI API Gateway built in Java (Maven), deployed on GCP, with three project phases and a UML use-case diagram.
